# ZJUT-credit-card-fraud-detection
信用卡欺诈检测系统

> 一个真实银行风控场景的最小可行产品（MVP），目标将漏检率从30%压到10%以下。

## 🎯 项目价值
- 全球每年因信用卡欺诈损失超 **350亿美元**
- 传统规则引擎漏检率高达 **30%**
- 我们的目标：用机器学习把漏检率压到 **10%以下**

## 🛠️ 技术栈全景图

| 层级 | 技术 | 选型理由 | 关键细节 |
|------|------|----------|----------|
| 数据层 | KaggleHub + SHA256 校验 | 确保数据零篡改 | 自动拉取官方数据集，校验完整性 |
| 特征层 | Amount/Time 标准化 | 合规要求“不可解释特征”显式声明 | 其他28维特征保持原样 |
| 样本层 | SMOTE + 严格 train/test split | 杜绝数据泄露 | 仅在训练集内过采样 |
| 模型层 | Logistic Regression, Random Forest, SVM | 稳健可解释 | 5折分层交叉验证，Random Forest AUC=0.98, Recall=0.82 |
